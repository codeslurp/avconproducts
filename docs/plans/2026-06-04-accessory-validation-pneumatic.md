# Accessory Validation (Pneumatic + PVP relabel) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a Pneumatic actuator is resolved, restrict the accessories picker to an allowlisted set of families (hard-lock + auto-clear the rest), and correct the mislabeled "PTR / Positioner Transmitter" family to "PVP / Pneumatic Valve Positioner".

**Architecture:** Frontend rule-config + enforcement in `AccessoryPicker` (`app/static/app.js`). The actuator's class is read from the existing resolved-event `detail.key` prefix (`pneumatic_*` → Pneumatic, `electrical_*` → Electric, else none). A pure `evaluateFamilies()` function computes the allowed family set; `AccessoryPicker._applyValidation()` applies it to the dropdown, datalist, search, and current selection. The PVP relabel is a data change in `accessories.py` that flows to the static site via `tools/build_static.py`.

**Tech Stack:** Python 3.14 (`py`), openpyxl (data load), vanilla JS (no build/transpile, no JS test runner), Flask (dev server via `run.bat`), static GitHub Pages bundle in `docs/`.

**Working location:** ALL paths below are inside `C:/Users/skarnik/repos/avconproducts` (the version-controlled repo that deploys). Branch: `docs/accessory-validation-spec` (already checked out).

**Scope:** Pneumatic ruleset + PVP relabel only. The Electric ruleset is intentionally left as an empty `allow: []` slot (do not ship Electric until the user supplies its allowlist).

**Spec:** `docs/specs/2026-06-04-accessory-validation-design.md` (rev 2).

/* Classify an actuator section key into the class the accessory rules use.
   Section keys are like "pneumatic_rp", "electrical_rotary", "manual_lever"
   (see catalog.py). Valves and manual actuators return null (no ruleset). */
function actuatorClassFromKey(key) {
  if (typeof key !== "string") return null;
  if (key.startsWith("pneumatic_")) return "Pneumatic";
  if (key.startsWith("electrical_")) return "Electric";

}

## Task 4: Add the ruleset config + pure `evaluateFamilies()`

**Files:**
- Modify: `app/static/app.js` — insert just before `class AccessoryPicker` (line ~689)

- [ ] **Step 1: Add the config and evaluator**

```javascript
/* ---------- Accessory validation rules ----------
   Family keys are the data_keys from ACCESSORY_FAMILY_ORDER (app/accessories.py).
   Pneumatic is fully specified; Electric is an intentional empty slot until the
   user supplies its allowlist (do NOT ship Electric behavior with allow: []). */
const POSITIONER_KEY = { Pneumatic: "Positioner", Electric: "EVP" };

const ACCESSORY_RULESETS = {
  Pneumatic: {
    allow: ["SV", "LSB", "Positioner", "FRG", "CFLG", "Gland",
            "Silencer", "FCV", "ALR", "QEV", "BKT", "THW FOR MSD"],
    conditionals: ["cflgNeedsValve", "svExcludesPositioner"],
  },
  // Electric: PENDING user allowlist. Left undefined on purpose so an Electric
  // actuator currently falls through to "no ruleset -> unrestricted" rather than
  // silently blocking everything. Fill in { allow:[...,"EVP"], conditionals:[...] }.
};

/* Pure, DOM-free. Returns { allowed, reasons }:
   - allowed === null  -> unrestricted (no actuator class / no ruleset).
   - allowed: Set<familyKey> of families that may be selected.
   - reasons: Map<familyKey, string> human reason for specific conditional blocks. */
function evaluateFamilies({ actuatorClass, valvePresent, selectedFamilies }) {
  const reasons = new Map();
  const rs = actuatorClass && ACCESSORY_RULESETS[actuatorClass];
  if (!rs) return { allowed: null, reasons };

  const allowed = new Set(rs.allow);
  const sel = new Set(selectedFamilies || []);

  if (rs.conditionals.includes("cflgNeedsValve") && !valvePresent) {
    allowed.delete("CFLG");
    reasons.set("CFLG", "needs a valve");
  }
  if (rs.conditionals.includes("svExcludesPositioner")) {
    const posKey = POSITIONER_KEY[actuatorClass];
    if (sel.has("SV") && posKey) {
      allowed.delete(posKey);
      reasons.set(posKey, "mutually exclusive with Solenoid Valve");
    }
    if (posKey && sel.has(posKey)) {
      allowed.delete("SV");
      reasons.set("SV", "mutually exclusive with the positioner");
    }
  }
  return { allowed, reasons };
}
```

- [ ] **Step 1: Add `_applyValidation()` and `_showNotice()` to the class**

```javascript
  /* Recompute allowed families and enforce: disable blocked dropdown options,
     filter the datalist, and auto-clear any selected accessory now blocked. */
  _applyValidation() {
    const { allowed, reasons } = evaluateFamilies({
      actuatorClass: this.actuatorClass,
      valvePresent: this.valvePresent,
      selectedFamilies: [...this.selected.keys()],
    });
    this._allowed = allowed;
    this._reasons = reasons;

    // Family dropdown options (skip the empty "All families" option).
    for (const opt of this.familySel.options) {
      if (!opt.value) { opt.disabled = false; continue; }
      opt.disabled = !!(allowed && !allowed.has(opt.value));
    }
    // If the active dropdown family just became blocked, fall back to all.
    if (allowed && this.familySel.value && !allowed.has(this.familySel.value)) {
      this.familySel.value = "";
      this._onFamilyChange();
      return; // _onFamilyChange calls _fillDatalist; avoid double work
    }

    // Auto-clear selected accessories whose family is now blocked.
    if (allowed) {
      const removed = [];
      for (const fam of [...this.selected.keys()]) {
        if (!allowed.has(fam)) { this.selected.delete(fam); removed.push(fam); }
      }
      if (removed.length) {
        const n = removed.length;
        this._showNotice(`${n} accessor${n > 1 ? "ies" : "y"} removed — not valid for ${this.actuatorClass} actuators`);
        this._renderChips();
        this._broadcast();
      }
    }
    this._fillDatalist();
  }

  _showNotice(msg) {
    this.noticeEl.textContent = msg;
    this.noticeEl.hidden = false;
    if (this._noticeTimer) clearTimeout(this._noticeTimer);
    this._noticeTimer = setTimeout(() => { this.noticeEl.hidden = true; }, 4000);
  }
```
